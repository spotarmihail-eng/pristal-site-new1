ПРОМОКОДЫ SMP

Добавлен отдельный раздел с интерфейсом промокодов.

Для каждого кода предусмотрены:
- сам код
- скидка в %
- лимит использований
- текущее количество использований
- награда
- срок действия (можно добавить в API)

Демонстрационные коды:
PRISTAL10 — 10%, 100 использований, +100 Pristal Coins
SKRENH20 — 20%, 50 использований, +1 Network Key
WELCOME — 5%, без лимита, +50 Pristal Coins

ВАЖНО:
Настоящая выдача скидки/награды не должна выполняться только JavaScript-кодом на GitHub Pages.
Для production нужен backend/API с базой и атомарным списанием лимита, чтобы два человека одновременно не использовали последний доступный промокод.
