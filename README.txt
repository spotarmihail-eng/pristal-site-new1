НОВОСТИ ИЗ DISCORD:
Сайт автоматически получает последние 10 сообщений канала ID 1486375854006206494. Workflow GitHub Pages синхронизирует новости каждые 10 минут.

Чтобы включить автоматическую ленту:
1. Создайте Discord-бота в Discord Developer Portal (или используйте уже существующего бота).
2. Добавьте бота на ваш Discord-сервер и дайте ему права View Channel и Read Message History именно в канале новостей. Для обычного чтения сообщений privileged Message Content Intent может понадобиться включить на странице Bot в Developer Portal.
3. В GitHub откройте репозиторий сайта → Settings → Secrets and variables → Actions → New repository secret.
4. Имя секрета: DISCORD_BOT_TOKEN. Значение: токен Discord-бота. Не вставляйте токен в HTML, JS или сообщения.
5. Откройте Actions → Deploy Pristal to GitHub Pages → Run workflow, либо дождитесь следующего автоматического запуска. При успешном подключении лента появится на сайте.

Проверка: в Actions должен завершиться workflow Deploy Pristal to GitHub Pages. Если новостей нет, проверьте токен и права бота на канал. Секрет хранится в GitHub Actions и не отправляется в браузер.

Сайт остаётся статическим и совместим с GitHub Pages; Discord API вызывается только из GitHub Actions.

ВХОД ЧЕРЕЗ DISCORD:
Кнопка «Войти через Discord» в шапке использует OAuth2 (implicit grant, scope identify). Сайт получает только ник и аватар; токен не сохраняется.
1. Откройте discord.com/developers/applications → ваше приложение (или New Application) → OAuth2.
2. Скопируйте Client ID и вставьте в index.html: const CLIENT_ID="..." (блок pristal-discord-auth). Client ID — не секрет.
3. OAuth2 → Redirects → Add Redirect: адрес сайта ровно как в браузере, со слэшем в конце, например https://ник.github.io/pristal-site/
4. Client Secret на сайт НЕ вставляйте.
Важно: профиль хранится только в браузере посетителя. Списка зарегистрированных пользователей у сайта нет, а закрывать что-либо «входом» нельзя — для этого нужен сервер.
